# 🍔 CraveBite - Food Delivery Website

A modern and responsive **Food Delivery Web Application** built to provide users with a fast and convenient way to explore food, discover offers, track orders, and manage their food delivery experience.

The application features a clean and attractive user interface focused on delivering a smooth and user-friendly experience.


---

## 📸 Project Preview

CraveBite provides a modern food delivery landing page with features such as:

* 🍕 Food discovery
* 🔥 Deals and special offers
* 🚚 Fast food delivery
* 📍 Location-based food search
* 🛒 Shopping cart
* 📦 Order tracking
* 🍽️ Table booking
* ⭐ Customer ratings
* 🔐 User authentication
* 📱 Responsive design

---

## ✨ Features

### 🍔 Food Delivery

Users can explore different food options and find meals available for delivery.

### 📍 Location Search

Users can enter their location to find available food delivery services in their area.

### 🚚 Fast Delivery

The platform highlights fast food delivery services with estimated delivery times.

### 🛒 Shopping Cart

Users can add food items to their cart and manage their orders before checkout.

### 📦 Order Tracking

Customers can track their food orders and monitor the delivery process.

### 🍽️ Table Booking

The application provides a table booking option for customers who want to reserve a table.

### 🔐 User Authentication

Users can sign in or create an account to access personalized features.

### 🎁 Deals & Offers

Customers can discover special promotions, discounts, and food offers.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1️⃣ Clone the Repository

```bash
git clone <your-repository-url>
```

### 2️⃣ Navigate to the Project Folder

```bash
cd client
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Run the Development Server

```bash
npm run dev
```

### 5️⃣ Open the Application

Open your browser and visit:

```text
http://localhost:3000
```
